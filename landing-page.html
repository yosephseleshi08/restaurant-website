Frequently Asked Questions

Everything you need to know before buying.

Do I need to know how to code?
No. The platform includes a visual editor where you can change colors, fonts, menu items, hours, and content without touching any code. If you want to customize deeper, the source code is fully documented and uses standard Python/Flask.
Where is it hosted?
You host it. We provide a Docker setup that works on any VPS (DigitalOcean, Linode, AWS), shared hosting with Python support, or platforms like Render, Railway, and Fly.io. You own the deployment and the data.
Is there a monthly fee?
No. This is a one-time purchase. You pay $999 (or $1,999 for agencies) once and own the software forever. Your only ongoing cost is your server hosting, which starts at $5-10/month on most VPS providers.
Can I resell this to my clients?
Yes — with the Agency License ($1,999). You can deploy it for unlimited clients, white-label it with your branding, and charge whatever you want. You keep 100% of what your clients pay you.
What about updates?
All buyers receive lifetime access to updates. When we release v2.1, v3.0, etc., you get the new version at no extra cost. Updates are delivered as a new ZIP file with migration instructions.
What payment methods do you accept?
We accept PayPal, Stripe (credit/debit cards), and bank transfer. After payment, you receive an instant download link to the full source code ZIP file.
