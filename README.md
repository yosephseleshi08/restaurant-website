# 🍝 La Bella Cucina — Restaurant CMS Pro v2.0 (React SPA)

A modern, full-featured digital toolkit for independent restaurants rewritten in React 18, TypeScript, and Tailwind CSS on Vite.

## Features

### 1. Customer-Facing Digital Experience
- **Hero & Landing Page**: Ambient Tuscan design, commission-free ordering value propositions, signature dishes, customer testimonials, and quick reservation booking widget.
- **Online Culinary Menu**: Categorized menu (Antipasti, Primi, Secondi, Pizza, Dolci, Drinks), dietary badges (Vegetarian, Vegan, Gluten-Free, Chef Special), price tags, and direct order quick actions.
- **Direct Online Ordering & Cart**: 0% commission direct ordering, delivery/pickup switcher, auto sales tax and free delivery threshold calculations, and instant ticket dispatch to the kitchen display.
- **Table Reservation System**: Live date/time slot picker, capacity safeguards (preventing overbooking), party size selection, and instant booking confirmation cards.
- **Live SMS Waitlist**: Real-time queue duration estimate, self-service sign-up, and host notification tools.
- **QR Table Self-Ordering**: Dine-in self-service ordering for tables (1–12) sending orders directly to line chefs.
- **Private Dining & Events**: Banquet packages, sommelier wine tastings, upcoming culinary calendar, and event inquiry forms.
- **Photo Gallery**: Atmospheric photo grid with category filters and full-screen image lightbox.
- **Rewards & Loyalty Program**: 1 point per $1 spent, 100 points = $10 discount, instant 50 bonus points on signup, and email balance lookup.
- **Digital Gift Cards**: Customizable value card designer with instant redemption code generation and balance checker.
- **Inquiry & Contact**: Structured inquiries (General, Reservation, Catering) with instant response storage.

### 2. Operations & Backoffice Command Center
- **Executive Dashboard**: Real-time metrics (total reservations, active orders, revenue, customer satisfaction ratings) and quick launch shortcuts.
- **Kitchen Display System (KDS)**: Real-time high-contrast ticket display for line cooks with status progression (`pending` -> `preparing` -> `ready` -> `completed`), time elapsed indicators, and customer notes.
- **Interactive Floor Plan**: Draggable table layout with seat capacities and live status colors (Available, Occupied, Reserved, Cleaning).
- **Reservations & Orders Ledgers**: Searchable and filterable tables with status updates and CSV export.
- **Customer CRM Database**: Member spending history, visit counts, favorite dishes, and loyalty point totals.
- **Message Inbox**: Customer inquiry manager with direct reply and archiving capabilities.
- **Visual CMS Editor**: Edit restaurant details, customize branding and theme colors, toggle feature modules, add/remove menu dishes, and manage staff user accounts.

## Running Locally

```bash
npm install
npm run dev
```

Dev server runs on port 3000 (`http://localhost:3000`).

## Admin Demo Access
Click the **Quick Demo Admin Access** button in the top banner, or navigate to `/login` with credentials `admin` / `admin123`.
